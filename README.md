# Adaptive FIR System Identification Using LMS-Type Algorithms

## Overview  

This project investigates the performance of three adaptive filtering algorithms:  
- Standard LMS
- Sign-LMS
- Sign-Sign LMS
  
for identifying an unknown Butterworth LTI system.  

## Technologies  
- MATLAB
- Python
- DSP
- Adaptive Filtering

## Results  
Standard LMS achieved the fastest convergence and lowest steady-state error.
